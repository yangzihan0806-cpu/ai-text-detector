How it works, how accurate it is, and its limits

Model. GPT-2 small (124M parameters), pretrained by OpenAI and fine-tuned for classification as in chapter 6 of Build a Large Language Model (From Scratch) by Sebastian Raschka. Only the last transformer block, the final LayerNorm and a new two-way output layer were trained.

Training data. The HAP-E corpus: human passages next to continuations of the same passages written by GPT-4o, GPT-4o-mini and Llama-3 (8B and 70B). Formatting differences between the two sources were removed so the model has to learn the writing itself.

Accuracy. On held-out HAP-E texts the ROC AUC is 0.97. Texts from chat models are caught about 95% of the time; texts from Llama-3 base models only 67–77% of the time. On a data set the model never saw (HC3, 2022 ChatGPT answers) the AUC is 0.99, but about 1 in 10 human answers crossed the 0.817 line. This web version stores the weights in 8 bits to make the download smaller; on 420 test texts it gives the same verdict as the original model 99.5% of the time, with the same accuracy.

Limits.

  • English only. Trained on passages of about 500 words; short texts are unreliable.
  • It never saw newer models (GPT-5, Claude, Gemini) or AI text that a person edited or paraphrased.
  • Some human writing will be marked as AI. Do not use this result on its own to accuse anyone of using AI.
